# N06 Integration Contract v2

N06 remains the cognition, synthesis, audit and governance nucleus. Existing cognitive modules are preserved.

## Canonical identity
N06 peers are N01, N02, N03, N04 and N05.

## Five IN / five OUT
N06 exposes one logical IN and one logical OUT for every other nucleus. These are logical channels and do not imply live deployment connectivity.

## Hybrid transport
N06 communicates through the common transport-neutral contract: IN_PROCESS, WEBVIEW_BRIDGE, LOOPBACK_HTTP, HTTP or REALTIME.

## AI provider boundary
N06 must not be architecturally identified with Gemini or any other provider. Provider-specific services remain compatibility layers only; AI-dependent cognition resolves through the abstract Soul AI Provider/Web Session supplied by the runtime/Pilot.

## Synergy
N06 consumes perception/context, conversation, artifacts and orchestration signals and returns synthesis, reasoning, audit and governance outputs. It can participate in parallel work and must preserve correlation metadata.

## Proof rule
A cognitive task is successful only when the actual target handler executes and returns a correlated result. Adapter presence is not proof.
